Desktop UI 无法正常使用时

          

            官方桌面端打不开或无法正常进行 AI 会话时（引擎异常、插件不兼容、界面卡住等），
            可以改用托盘自带的 Web UI 继续工作——两者是同一台机器上的两个界面，已保存的会话与设置不会因为切换而丢失。
          

          
    
            
  1. 点下方「切换到 Web UI」：托盘会启动后台服务并把托盘「打开」指向网页端（首次启动可能需要下载运行环境，耗时数分钟）。
    2. 
            
  2. 服务就绪后，点托盘菜单「打开 Web UI」，或回到本页点「打开 Web UI」（切换到 Web UI 后本页会显示该按钮）。
    3. 
            
  3. 桌面端问题排查完、想改回桌面端时，到「常规」页把「默认启动方式」切回 Desktop UI 即可（后台服务会随之停止）。
    4. 
          

          

            
          

          

        

        
        

          
Web UI 提示“需要重新鉴权”

          
打开 harness 网页端时浏览器显示：dsh web authentication required; reopen the URL printed by dsh web.

          
后台服务未运行：启动服务后即可打开 Web UI 或复制访问链接。

          

          

            
没有找到带访问令牌的链接：服务不是由本程序拉起的（例如上次退出时保留了服务，或电脑重启后服务仍在运行），日志轮转也可能丢失该行。浏览器此前已正常登录过 → 直接点「打开 Web UI」；换浏览器或不带记录的窗口 → 先点下方「重启后台服务」生成新链接。

            

              
            

          

          
原因：后台服务每次启动都会更换访问令牌（安全设计）——旧书签与历史记录里的地址随即失效；浏览器中还没有有效凭据（首次打开、清理过 Cookie，或凭据已超过 30 天）。

          
    
            
  1. 点击下方「打开 Web UI」，它会自动使用最新的访问链接。
    2. 
            
  2. 或点击「复制访问链接」，粘贴到浏览器地址栏打开。
    3. 
            
  3. 请按链接原样打开（地址是 127.0.0.1）——凭据与地址绑定，不要改写成 localhost。
    4. 
            
  4. 仍打不开时，点「重启后台服务」重新生成访问链接，再回来重试。
    5.
