WHY DSH-SYSTRAY

为桌面而生，安静地工作

不弹窗、不占标签页，像系统原生的一部分。

启动与托盘

  • 双击启动无窗口、后台拉起本地 Web 服务，无需记忆端口。
  • 托盘常驻图标一望即知，深浅色自动适配，不占任务栏。
  • 启动 loading服务启动期间进度可视化，就绪后弹窗提示。
  • 单实例已在运行时再次双击会弹窗提示，不重复启动。

设置与管理

  • 设置窗口五页分类：常规、关于、日志、导出、导入。
  • 实时日志app.log / server.log 跟随最新写入，可复制、一键清空。
  • 数据导入导出会话、插件、目录打包 zip，导入冲突询问、自动恢复。
  • 自动更新后台检查新版本，进度窗口下载，完成自动重启。

安装说明

  1. 下载对应平台 zip 并解压到任意目录
  2. Windows：双击 dsh-systray.exe（SmartScreen 提示时选「仍要运行」）
  3. macOS：首次右键 → 打开 dsh-systray，绕过 Gatekeeper
  4. 首次启动约需 2-5 分钟完成环境部署，随后自动打开服务；配置保存在用户目录的 config.json
