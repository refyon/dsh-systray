WHY DSH-SYSTRAY

轻量、可靠、可迁移

单文件、自愈、随身带。像系统原生的一部分。

轻量 — 双击即用

  • 双击即启服务在后台安静就绪，不用记端口，不用开终端。
  • 单文件免安装Windows 单 exe / macOS 单 app，免管理员权限，解压即用。
  • 常驻托盘一望即知服务状态，深浅色随系统自动切换。
  • 始终唯一不会重复启动，托盘里永远只有一个它。

可靠 — 自动自愈

  • 启动看得见每一步进度清晰呈现，就绪后贴心提醒。
  • 启动失败自动回退启动异常时自动回退到上次正常运行的 harness 与插件状态。
  • 更新失败自动回滚harness 与插件更新前自动快照，失败自动还原并重启校验。
  • 日志实时跟随最新记录自动呈现，需要时一键清空。

可迁移 — 数据随身带

  • 数据随身带会话与插件一键打包，换台机器也能无缝恢复。
  • 冲突智能处理导入时逐项恢复、冲突询问，自动备份现有内容。
  • 配置即数据配置与数据都在用户目录，随导出包完整迁移。
  • 跨平台一致Windows / macOS 同一套界面、同一份数据格式。

开始使用

  1. 下载对应平台 zip 并解压到任意目录
  2. Windows：双击 dsh-systray.exe（SmartScreen 提示时选「仍要运行」）
  3. macOS：首次右键 → 打开 dsh-systray，绕过 Gatekeeper
  4. 首次启动约需 2-5 分钟完成环境部署，随后自动打开服务；配置保存在用户目录的 config.json
  5. 换机迁移：旧机器「导出」打包 zip，新机器「导入」逐项恢复会话、插件与文件目录
