WHY DSH-SYSTRAY

为桌面而生，安静地工作

不弹窗、不占标签页，像系统原生的一部分。

托盘常驻

无窗口后台拉起本地 Web 服务，图标一望即知，不占任务栏。

设置窗口

五页分类：开机自启、版本更新、实时日志、导入导出。

实时日志

app.log / server.log 自动跟随最新写入，支持复制与一键清空。

数据导入导出

会话、插件、目录打包 zip 备份，导入冲突询问、自动恢复。

自动更新

后台自动检查新版本，进度窗口下载，完成后自动重启。

主题自适应图标

托盘图标随系统深浅色自动切换，任何主题下都清晰可见。

安装说明

  1. 下载对应平台 zip 并解压到任意目录
  2. Windows：双击 dsh-systray.exe（SmartScreen 提示时选「仍要运行」）
  3. macOS：首次右键 → 打开 dsh-systray，绕过 Gatekeeper
  4. 首次启动约需 2-5 分钟完成环境部署，随后自动打开服务；配置保存在用户目录的 config.json
