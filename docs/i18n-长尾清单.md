# i18n 长尾文案清单（剩余枚举）

> 用途：逐轮推进「需求 3b-3（前端动态长尾）+ 3c（Go 原生 UI）」的翻译盘点与收敛。
> 度量口径：`codeCjk ≈ 去掉注释后仍含 CJK 的行数`（含字符串字面量与多行拼接，非精确句数）。

## 0. 现状快照（已完成的双语面）

- 前端静态层：五页/splash/三弹层 data-i18n（EN 字典）✅
- 前端核心动态层：服务状态、检查更新、端口提示、重置计数、插件操作态、导出/导入结果、取消文案 ✅
- 前端边界自动翻译：`confirmDialog3 / setNote / impRowText / fmt()` 统一 `tr()`——**静态句只需入字典即可生效，无需再逐条改调用点** ✅
- Go 侧：`T()/TF()` 基础设施 + 托盘菜单/服务状态/就绪弹窗 ✅（其余大量 splash/MessageBox 文案未翻）

## 0.5 文案边界（用户决策 2026-09-06）

- **翻译**：界面骨架——托盘菜单、服务状态、弹窗标题/主问句/按钮、splash 阶段通用标签、导出/导入结果骨架、确认/取消等。
- **保留中文（与日志同策略）**：具体错误原因细节（npm/网络/路径/校验等 Go 端透传 error/note 与 MessageBox 原因句）、插件/路径/版本等专有内容。
- 效果：EN 界面下出错时“原因行”可能仍为中文，属既定行为，不视为缺口。

## 1. 前端 `frontend/dist/main.js`

已字典化的句式集中在更新/服务/插件操作/导出导入结果；剩余分类：
- **插件行/导出行/导入行模板 HTML 字符串**（renderPlugins / impRows / expRows 内的 zh 片段 + 按钮文案 + 来源标签 `PLUG_SRC_LABEL` 等）——需把模板内的静态 zh 片段提成字典键（或整行模板键 + 插值）。
- **confirm/提示的长句（含插值）**：调用点拼接的 msg（如删除插件消息含 name/profile）——需改成 `fmt(templateKey, …)` 形态才能进字典。
- **日志页/重置弹层动态行**：`loadVersions` 说明、`reset-target-note`、倒计时/恢复中状态等零散句。
- **Go 事件透传文案**（import:progress / export:progress / splash 文本本身是中文）——归 Go 侧处理（见 §3），前端 `tr()` 无法覆盖动态长句。

建议顺序：模板静态片段字典化 → 插值句改 fmt 模板 → 与 §3 Go 透传句在 Go 侧 T()。

## 2. 前端 `frontend/dist/index.html`（~87 含中文行，均已挂 data-i18n/data-i18n-ph）

仅剩少量非文案（注释/aria 残留），检查项：grep 未覆盖属性里的中文字符串（title/alt/placeholder/aria-label 未 key 的）。

## 3. Go 原生 UI（约剩 ~200 处面向用户句；CJK code 行合计约 576，去掉日志后≈此量级）

| 文件 | 主要 UI 文案类型 | 建议 |
| --- | --- | --- |
| updater.go (~88) | splash 阶段文案、更新/回滚 MessageBox、错误原因 | T()/TF() + dict（进行中） |
| plugin_update.go (~117) | 插件更新/回退/禁用 MessageBox 长文案 | dict + 复用导出导入词汇 |
| exportimport.go (~60) | 导出/导入完成与冲突提示 | dict |
| harness_reset.go (~42) | 重置进度/结果弹窗 | dict |
| import_flow.go (~27) | 恢复进度与说明 | dict |
| app.go (~100) | logUI 日志（不译）+ 少量 UI 句 | 只译面向用户句，日志保持中文 |
| platform_*.go (~93) | ask*/MessageBox/AppleScript 弹窗 | T()（就绪弹窗已做） |
| main.go (~49) | tray/提示/状态句 | tray/服务状态已做，其余分批 |

原则：`log.Printf/logUI/unified log` **不译**（诊断面）；splash 阶段文案、MessageBox、ask*、tray、服务状态等面向用户才进 T() 字典。

## 4. 词汇表对齐

zh↔en 用词统一参考 `docs/i18n-glossary.md`（若已建）；目前站点/README/前端各自维护，后续把常用词（恢复/回退/自愈/预发布/导出包等）抽到共享词典避免三处不一致。

## 5. 每轮验收

1. `node --check frontend/dist/main.js`；
2. 字典键与用法自检（新增键可运行在 `?lang=en` 前用临时脚本 grep 校验覆盖）；
3. `go build ./... && go test ./...`；
4. Windows 本地以 `language=en` 起 app 走读受影响页面；
5. 截图受影响页面对比 zh/en（docs/shots-en 已具备管线）。

## 6. 收尾定义（DoD）

- 前端 main.js 无面向用户的中文硬编码残留（grep CJK 仅剩注释/日志）；静态+插值句全部走字典；
- Go 用户可见文案（tray/splash/MessageBox/ask）全部 T()，日志保持中文；
- docs/shots-en 六页重拍无中文界面元素（插件名等真实内容除外）；
- README.en / 网站 / app 术语一致性走查通过。
